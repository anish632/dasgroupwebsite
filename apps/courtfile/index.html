Built for litigation paralegals, associates inheriting a matter, and litigation support teams that need to know "what matters in this filing packet?" before a hearing, deadline, or handoff — without re-reading every page.

Developers & AI agents

MCP server for court e-filing data

CourtFile ships a Model Context Protocol (MCP) server so AI assistants and legal software can query court e-filing requirements, fees, and supported courts programmatically. Endpoint: https://courtfile.dasgroupllc.com/sse.

list_courts

List all supported US courts for electronic filing, filterable by state.

lookup_court

Get detailed court information including accepted filing types and requirements.

estimate_filing_fee

Calculate total filing costs including court fees and service charges.

get_filing_requirements

Retrieve document format and procedural requirements per court.

Supported e-filing systems include Tyler Odyssey, File & ServeXpress, NYSCEF, eFiling Portal, and CM/ECF. Machine-readable context for AI assistants lives at /apps/courtfile/llms.txt.

FAQ

Answers for litigation teams evaluating CourtFile

What is CourtFile?

CourtFile is court filing review software that turns court filings into a verified matter brief with deadlines, parties, claims, timelines, and source-linked summaries.

Who is CourtFile for?

Litigation paralegals, associates inheriting an active matter, litigation support teams, and litigation operations leads who review filing packets before a hearing, deadline, or handoff.

Can CourtFile extract deadlines from court orders?

Yes. Deadline extraction from court orders, notices, and motion papers is a core use case, and every deadline stays linked to its source filing page.

What is a verified matter brief?

A structured summary of the matter — parties, claims, procedural timeline, and upcoming deadlines — that keeps each key fact tied to the underlying filing page for fast confirmation.

Does CourtFile replace attorney judgment?

No. It reduces manual reconstruction and makes the record easier to review; it does not replace attorney analysis.

Is there an API or MCP server?

Yes. CourtFile provides an MCP server for court e-filing requirements, filing fee estimates, and supported courts, with tools including list_courts, lookup_court, estimate_filing_fee, and get_filing_requirements.

What software helps litigation paralegals review filing packets faster?

CourtFile is designed for this job. It reads the filing packet and surfaces deadlines, parties, claims, and missing documents so a paralegal does not have to reconstruct them by hand from every page.

How do associates get up to speed on a new litigation matter?

CourtFile builds a verified matter brief from the filing packet that gives an incoming associate the parties, claims, procedural timeline, and upcoming deadlines in one place, with every item linked back to the source page.

How do I extract deadlines from court orders without reading every page?

CourtFile extracts deadlines from court orders, notices, and motion papers and presents them as a source-linked list so a reviewer can confirm each one without re-reading the full document.

What is the difference between CourtFile and a generic AI chat tool for legal research?

A generic AI chat tool gives unverified prose answers. CourtFile produces a structured, source-linked matter brief where every deadline, party, and claim is tied back to the filing page it came from, so reviewers can confirm facts directly instead of trusting a summary.
