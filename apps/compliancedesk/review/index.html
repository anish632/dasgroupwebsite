Compliance Desk

Three test designs

Download each PDF and import it into Canva as a new design. The source files contain separate text and vector rectangles, not flattened screenshots. Confirm that text can be selected and edited after import, then open Compliance Desk and scan the current page.

  1. Clean baseline — With default rules, the source fixture produces no issues. This is a scanner baseline, not a compliance certification.
  2. Financial claims — Includes guaranteed returns, no-risk wording, implied regulatory approval, projected and backtested returns, and an insurance claim. Expect multiple review flags and missing-disclosure warnings. Add Past performance is not a guarantee and rescan to test the performance-disclosure signal; other claim flags should remain.
  3. Safe fixes — Includes a double space in Plan your next and orange rectangles. Under Rules → Brand, add #123456, #187C80, #FFFFFF, and #EFF5F5 as approved colors. Scan, apply the spacing and off-brand color fixes, then scan again. If PDF import normalizes the double space, re-enter it in the headline before scanning.

The source fixtures were checked against the current local rule engine. Import behavior and execution inside Canva have not yet been verified. All sample branding and copy are fictional and intended only for app testing.
